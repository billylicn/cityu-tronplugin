1. 核心说明

重要区分：本扩展会在用户设备上“处理”学习数据，但不会把课程、任务、考勤、姓名或学号发送至作者或作者控制的服务器。本扩展没有开发者后端、用户账号系统、广告 SDK、统计 SDK或遥测服务。

扩展使用用户当前已登录的 TronClass 会话，直接向澳门城市大学 TronClass 及其课程文件媒体域名发出请求，以向用户展示其本来就有权查看的内容。用户的浏览器会按照网站正常机制附带登录会话信息；扩展不会读取、复制或保存 Cookie、密码或 JWT。

本政策中的“本地缓存”是指保存在当前 Chrome 浏览器配置文件的 chrome.storage.local 中的数据。“去除直接身份字段”不代表课程名称、活动标题或记录组合在任何情况下都绝对无法识别用户，因此这些数据仍应由用户妥善保护。

2. 适用范围与责任主体

本政策适用于开源浏览器扩展 CityU TronClass Plugin。项目维护者为 GitHub 用户 billylicn。本项目是非官方社区工具，与澳门城市大学、TronClass 或 Wisdom Garden Limited 不存在隶属、授权、认可或代理关系。

TronClass、课程文件媒体服务、GitHub、Chrome 浏览器和 Chrome 网上应用店对其各自服务中的数据处理适用其自己的条款与隐私政策。本政策仅说明本扩展自身的处理行为。

3. 本扩展处理的数据

数据类别具体内容处理位置与保存方式
账号确认信息 当前登录账号的姓名、学号。 仅在主动联网成功后的 Dashboard 页面内存中用于账号确认；不写入本地缓存，页面关闭或重新加载后不从缓存恢复。
内部技术标识 TronClass 内部用户 ID。 仅在内存中用于请求当前用户的出勤记录；不展示、不持久化。
课程与学习活动 课程名称和标识、学期信息、活动标题和标识、活动类型、开始与截止时间、完成和提交状态、分组标记、正式直达地址。 用于学习总览；经字段白名单处理后可保存在本地缓存。
出勤数据 点名记录时间、状态、课程、出席、迟到、缺席、事假、病假、其他状态及课程点名设置。 用于出勤展示和城大战绩；经字段白名单处理后可保存在本地缓存。
作业与报告数据 作业提交状态、缺交记录、统计数量、比例、等级、用户手动排除的记录键。 用于任务列表和城大战绩；可保存在本地缓存。
成绩展示数据 课程和学期、活动标题和类型、本人已提交状态、平台可见分数、成绩公布状态、权重、提交时间和正式直达地址。 用于成绩展示；经字段白名单处理后可保存在本地成绩缓存。不保存作答内容、问卷答案、提交记录 ID、教师评语或原始 API 响应。
课程文件元数据 文件名、类型、扩展名、大小、发布日期、上传或引用标识、是否允许下载或预览。 元数据可保存在本地缓存；文件内容、Blob 和短期签名地址不进入缓存。
页面偏好 栏目顺序、默认折叠状态、自动刷新设置、使用声明设置、被忽略任务、通知内容指纹。 保存在 chrome.storage.local，用于在下次打开时恢复用户选择。
公开版本信息 GitHub Releases 返回的最新公开版本号。 仅用于提示新版本，不附带课程或身份数据，不作为学习数据缓存保存。

本扩展不会主动收集或持久化的内容

  • TronClass 密码、Cookie 内容、JWT、完整请求头、登录 bootstrap 原始数据；
  • 作答内容、问卷答案、提交记录 ID、教师评语或成绩接口原始响应；
  • 邮箱、电话号码、证件号码、支付资料、精确地理位置；
  • 短期签名文件 URL、文件 Blob 或下载后的文件内容；
  • TronClass 以外网站的浏览历史、搜索记录或页面内容；
  • 广告标识、跨网站追踪标识、分析事件或崩溃遥测。

4. 数据处理目的

本扩展仅在提供用户明确可见的核心功能所必要的范围内处理数据，包括：

  1. 聚合展示用户有权访问的进行中或历史课程；
  2. 展示个人出勤摘要、异常次数和点名明细；
  3. 判断作业、讨论、问卷、测验、互动和分组学习的完成状态；
  4. 展示待提交、即将开始和逾期项目及其原站直达入口；
  5. 展示本人已提交作业、问卷和线上考试的可见成绩及公布状态；
  6. 展示课程文件并响应用户主动发起的下载或预览另存；
  7. 在本地生成城大战绩统计；
  8. 恢复用户设置和本地缓存，以及检查公开发布的新版本。

在适用法律要求的范围内，上述处理以用户主动安装、确认声明、使用扩展及主动请求相关功能为基础。用户可以随时停止使用、关闭自动刷新、清除缓存或卸载扩展。

5. 网络请求与第三方服务

扩展的网络访问被限制在以下 HTTPS 域名：

域名用途会发送什么
tronclass.cityu.edu.mo 读取课程、学习活动、出勤和课程文件元数据；打开登录页和课程直达页面。 浏览器会向 TronClass 发送正常的 HTTPS 请求，并按网站机制附带当前登录会话。作者不会接收这些请求。

6. 浏览器权限及理由

扩展仅申请当前功能所需的权限，不为未来可能加入的功能预先申请权限。

downloads

在用户主动点击下载或预览另存后，通过 Chrome 下载管理器保存 TronClass 课程文件，并尽可能保留原文件名。扩展不会自动批量下载，除非用户明确点击课程内的批量下载操作。

tabs

打开或聚焦扩展 Dashboard，并在用户点击后打开 TronClass 登录页、课程详情和项目 GitHub 页面。扩展不读取一般浏览历史，也不监控用户在其他网站的活动。

storage

在当前浏览器本地保存页面设置、经字段白名单处理的学习总览缓存、成绩缓存、战绩缓存、忽略与排除状态，以及通知内容指纹。

host permissions

仅允许扩展向 TronClass、课程文件媒体域名和 GitHub 公开 Release API 发出实现上述功能所需的 HTTPS 请求。

7. 本地存储、保存期限与删除

  • 页面内存数据：姓名、学号、内部用户 ID 和短期签名 URL 仅在相关页面或操作期间存在，不写入扩展本地缓存。
  • 学习总览缓存：保留至下一次成功刷新覆盖、用户点击“清除上次数据”、清除扩展数据或卸载扩展。
  • 成绩缓存：按平台学期保存经白名单处理的已提交项目成绩，保留至该学期下一次成功读取覆盖、用户点击“清除上次数据”、清除扩展数据或卸载扩展。
  • 城大战绩缓存：保留至下一次成功生成覆盖、用户清除数据或卸载扩展；重新生成会清空原有手动排除状态。
  • 页面设置：长期保留至用户修改、恢复、清除扩展数据或卸载扩展。
  • 已下载文件：由 Chrome 保存到用户选择或浏览器配置的下载位置，删除操作由用户自行完成。

设备安全提示：本地缓存位于用户的 Chrome 配置文件中。能够访问该操作系统账号、浏览器配置文件或设备备份的人，可能有机会接触这些数据。请使用设备锁、独立浏览器账号和适当的系统安全措施。

8. 数据分享、披露与出售

作者不接收、出售、出租或交易用户的学习数据，也不会把这些数据提供给广告商、数据经纪商或分析平台。

以下情况可能发生由用户控制或法律要求的数据传输：

  • 用户下载课程文件时，文件会由 TronClass 或其媒体域名传输至用户设备。
  • 如适用法律、法院命令或有权机关依法要求，相关主体可能需要依法处理数据；但由于作者没有接收或保存用户学习数据，通常没有可供作者披露的服务器副本。

9. Chrome Web Store 用户数据有限使用承诺

CityU TronClass Plugin 对通过 Chrome API、TronClass 页面和网络请求取得的数据的使用，将遵守 Chrome Web Store 用户数据政策，包括有限使用要求：

  • 数据仅用于提供或改进本政策和商店页面中明确披露的用户可见功能；
  • 不会用于个性化广告、再营销、兴趣画像、信用评估、保险或与学习辅助无关的目的；
  • 不会出售用户数据，也不会为广告、数据经纪或其他商业目的转移用户数据；
  • 作者及贡献者不会查看用户的课程、任务、考勤或文件内容；只有用户主动向项目维护者提供特定信息以请求技术支持时，维护者才会接触用户明确提供的内容；
  • 任何必要传输均通过 HTTPS，并限制为实现用户主动使用的功能所必需的目标域名和数据范围。

10. 安全措施与风险

项目采取的措施包括：Manifest V3、静态本地代码、禁止远程脚本、HTTPS 域名白名单、字段白名单缓存、短期签名 URL 不落盘、无广告与遥测、开源代码审查，以及仅在用户操作后执行下载。

扩展不会伪造下载权限、猜测隐藏地址、绕过访问控制、破解加密或 DRM，也不会尝试访问当前账号无权查看的课程内容。

任何软件、浏览器存储和网络传输均无法保证绝对安全。用户应保持 Chrome 和扩展为最新版本，并避免在公共或不受信任设备上保存学习缓存。

11. 用户选择与控制

用户可以通过以下方式控制扩展处理的数据：

  • 关闭“自动刷新”，阻止打开插件或刷新页面时自动请求 TronClass；
  • 使用“刷新数据”“生成城大战绩”等按钮决定何时主动联网；
  • 忽略或恢复特定任务，从战绩统计中排除或恢复特定记录；
  • 在“页面设置”中点击“清除上次数据”，删除学习总览、成绩和战绩缓存；
  • 通过 Chrome 的扩展管理页清除扩展数据或卸载扩展；

由于作者没有服务器端用户数据库，作者通常无法代用户查询、导出、更正或删除浏览器本地缓存。上述操作应在安装扩展的浏览器和设备上完成。

12. 政策变更

当扩展的数据类型、使用目的、权限、第三方服务或保存方式发生实质变化时，本政策将相应更新，并修改页面顶部的“最后更新”日期。需要新增权限的版本还可能由 Chrome 向用户显示权限变更提示。

如变更会实质影响用户数据处理，项目将通过扩展启动通知、GitHub Release 说明或项目页面进行提示。继续使用更新后的扩展前，用户应阅读最新政策。

13. 联系方式

如对本政策、扩展权限或数据处理方式有疑问，可以通过公开的 GitHub Issues 联系项目维护者。提出问题时，请勿提交密码、Cookie、JWT、包含个人信息的完整页面截图或未经处理的课程文件。
