# CityU TronClass Plugin

一个面向澳门城市大学学生的非官方 Chrome/Chromium 扩展，在本地统一展示 TronClass 的出勤、待提交作业、讨论、问卷、线上测验、互动、分组任务和课程文件。

项目主页：https://github.com/billylicn/cityu-tronplugin

## 使用方法

1. 打开项目的 [最新版本下载页面](https://github.com/billylicn/cityu-tronplugin/releases/latest)。
2. 在 **Assets** 中下载 `cityu-tronclass-plugin-vX.Y.Z.zip`。
3. 解压下载的 ZIP 文件；Chrome 不能直接加载 ZIP 压缩包。
4. 在 Chrome 地址栏打开 `chrome://extensions/`。
5. 开启右上角的“开发者模式”。
6. 点击“加载已解压的扩展程序”，选择刚才解压得到的目录。
7. 在同一浏览器中登录澳门城市大学 TronClass，然后点击工具栏中的扩展图标。

> 更新版本时，下载并解压新的 Release，然后在 `chrome://extensions/` 中移除旧版本并重新加载新目录。

## 隐私设计

- 纯静态 Manifest V3 扩展，无后端，不上传任何学习数据
- `chrome.storage.local` 保存页面设置、匿名学习总览缓存、匿名战绩缓存和战绩记录排除状态
- 缓存采用字段白名单，不保存姓名、学号、邮箱、内部用户 ID、Cookie、JWT、登录 bootstrap、请求头或其他身份字段
- 不保存临时签名 URL、Blob、文件内容、分享图片或下载内容
- 缓存可在“页面设置”中点击“清除上次数据”删除；布局、折叠和自动刷新设置会保留
- 自动刷新默认开启；关闭后，打开或重新加载插件以及切换到无缓存的课程范围均不会请求 TronClass
- “刷新数据”“生成城大战绩”和“重新生成”属于用户主动操作，即使自动刷新关闭也可联网读取
- 缓存模式不显示姓名和学号；主动联网读取成功后，身份信息仅在当前 Dashboard 页面内存中展示
- 不使用远程脚本、广告、统计或遥测
- 仅允许请求 `tronclass.cityu.edu.mo` 与 `tcmedia.cityu.edu.mo`

详细说明见 [`privacy.html`](privacy.html)。

## 从源码安装

1. 下载或克隆本项目。
2. 打开 Chrome 的 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目目录。
5. 在同一浏览器中登录澳门城市大学 TronClass。
6. 点击工具栏中的扩展图标打开 Dashboard。

## 开发与测试

项目没有运行时依赖或构建步骤。

```bash
npm test
npm run check
```

修改代码后，在 `chrome://extensions/` 中点击扩展的“重新加载”即可。

## 课程范围

扩展不使用电脑日期判断课程是否“进行中”。TronClass 课程列表按平台当前学期优先返回，扩展将与第一门有效课程具有相同 `semester.id` 的课程作为“进行中”；其余课程进入历史课程选择器。

## 城大战绩统计口径

- 首次进入报告页不会自动扫描；点击“生成城大战绩”后，以最多 2 门课程并发读取全部课程的普通作业和个人考勤。
- 拍卡次数为出席加迟到；缺勤次数为缺席、事假和病假，未知状态不进入缺勤率分母。
- 缺交率只统计已有明确截止时间、已经开放且截止时间已到的普通作业；每个作业活动只计算一次。
- 综合等级取缺勤率和缺交率中较高的风险；任一项达到 20% 时为 F。两项都没有有效分母时显示“暂无等级”。
- 报告只展示综合等级和固定称号，不生成自动评价或建议段落。
- 缺勤或缺交记录可从统计口径中排除；排除后会扣减相应分子与分母并重新评级，分享图同步使用当前有效报告。
- 排除状态随匿名战绩缓存保留；“重新生成”会清空排除状态，“恢复完整统计”会恢复全部记录。
- 分享图默认匿名，不含姓名和学号，也不会标注曾排除记录。

## 下载边界

- 官方允许下载：调用 `/api/uploads/reference/{referenceId}/blob`，不按扩展名限制 PDF、Office、压缩包、图片、音视频或其他附件。
- 允许完整文档预览：实时调用平台预览授权接口，且只接受 `tcmedia.cityu.edu.mo/download/file/` 下带签名的地址。
- 无法取得完整授权文件时只保留“查看活动”，不会尝试破解、拼接或绕过权限。
